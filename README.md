# JARVIS Clipper AI (Mobile-First + Cloudflare Pages & Workers AI)

Мобильное веб-приложение для автоматической нарезки длинных (2+ часовых) видео на короткие интересные фрагменты (1–2 минуты) без рекламы, с генерацией названий, описаний и хештегов, **автоматическим удалением исходного видео** и возможностью удалять папки с нарезками в 1 клик.

## Как подключить к GitHub и Cloudflare Pages (за 2 минуты)

1. Загрузите этот репозиторий на **GitHub**.
2. Зайдите в **Cloudflare Dashboard** → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
3. Выберите ваш репозиторий и укажите:
   - **Build output directory**: `public`
4. (Опционально) Для включения нейросети Llama 3.1 от Cloudflare:
   - Перейдите в настройки проекта Pages → **Settings** → **Bindings** → **Add** → **Workers AI** и назовите переменную `AI`.
5. Готово! Приложение работает на телефоне и можно добавить его на главный экран (PWA).
